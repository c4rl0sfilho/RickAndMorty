# 🚀 Rick and Morty Explorer - App Mobile em Kotlin  

Este é um aplicativo mobile desenvolvido em **Kotlin**, que consome a **API do Rick and Morty** para exibir informações sobre personagens, episódios e locais do universo da série. 📱🛸  

## 📌 Tecnologias Utilizadas  

- **Kotlin** ☕  
- **Retrofit** – Para consumo da API  
- **Jetpack Compose** – Para UI moderna e responsiva  
- **Coroutines** – Para chamadas assíncronas  

## 🛠 Como Executar o Projeto  

1. Clone o repositório:  
   ```bash
   git clone https://github.com/c4rl0sfilho/rick-and-morty-explorer.git
   ```  
2. Abra o projeto no **Android Studio**.  
3. Execute o app em um emulador ou dispositivo físico.
